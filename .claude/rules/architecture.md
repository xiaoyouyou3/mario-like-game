# アーキテクチャポリシー

## 層と依存方向
```
src/main.py → src/render/ → src/game/      （左が右に依存してよい。逆は禁止）
```
| 層 | 責務 | 禁止 |
|---|---|---|
| `src/game/` | 物理・衝突・敵AI・ステージ・スコア等のロジック。純Python | `import pygame`、ファイル/画面/音/実時間の直接アクセス |
| `src/render/` | `game` の状態を描画・入力を `game` の入力型へ変換 | ゲームルールの判断（当たり判定・得点計算など） |
| `src/main.py` | ループ・初期化・実時間の取得 | ロジックの実装 |

## ロジック層の作法
| 項目 | 基準 |
|---|---|
| 時間 | `update(self, dt: float)` で受け取る。`time.time()` / `pygame.time` を使わない |
| 乱数 | `random.Random` インスタンスを引数で受け取る。グローバル `random` 禁止 |
| 定数 | マジックナンバー禁止。物理定数は `src/game/constants.py` に名前付きで集約し、単位をコメントする（例: `GRAVITY = 900.0  # px/s^2`） |
| 状態 | 状態の持ち主は1か所。コピーを持ち回らない |
| 入力 | `InputState(left, right, jump_pressed, jump_held, run)` のようなデータクラスで受け取る。キーコードを知らない |
| 型 | 公開関数・メソッドは型ヒント必須。`Any` 禁止 |
| サイズ | 関数50行以内・引数5個以内・ネスト3段以内。超えたら分割（網羅的な `match` / テーブルは除く） |

## 実装スコープ
- 失敗しているテストが要求していない機能を足さない（YAGNI）。
- 後方互換コード・使われないフォールバック・デッドコードを残さない。
