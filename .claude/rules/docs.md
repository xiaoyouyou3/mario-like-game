# ドキュメントポリシー

| 項目 | 基準 |
|---|---|
| 1要件1文 | 「〜できる」「〜のとき〜する」で1文。「かつ」「および」で複数要件を束ねない |
| 禁止語 | 「快適に」「適切に」「スムーズに」「素早く」「簡単に」「など」「等」「必要に応じて」。数値か条件に置き換える |
| 受入条件 | 観測可能な値・状態で書く（例: 「最大水平速度 90 px/s を超えない」）。テストの期待結果にそのまま転記できること |
| 要件にHowを書かない | クラス名・ライブラリ名・アルゴリズム名は要件に書かない（設計で書く） |
| 設計にコードを書かない | 関数本体は書かない。シグネチャと責務まで |
| 未決事項 | 推測で埋めず「未決事項」節に質問として残し、ユーザーに確認する |
| 変更時 | ID は再利用しない。廃止は行を消さず「廃止」と理由を書く |
