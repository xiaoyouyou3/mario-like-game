# ヒアリング質問バンク

各質問は「選択肢（★推奨）」付きで聞く。決まった項目は requirements.md に即反映する。

## A. スコープ
1. ステージ数: ★1面（最小で縦に通す） / 3面 / 無限生成
2. 目的: ★学習（TDD・ハーネス検証） / 公開 / 友人に配る
3. 見た目: ★矩形と色のみ（画像なし） / ドット絵素材を使う（素材の出所を確認）
4. 音: ★なし / 効果音のみ / BGMあり

## B. プレイヤー
5. 操作: ★←→で移動、Zでジャンプ、Xでダッシュ / 矢印+スペース / ゲームパッド対応
6. ダッシュ（走り）: ★あり / なし
7. 可変ジャンプ（ボタンを早く離すと低く跳ぶ）: ★あり / なし
8. 被ダメージ: ★1回で死亡 / 1回耐える（パワーアップ要素が必要になる）
9. 残機: ★3 / 無限 / 1

## C. 敵とギミック
10. 敵の種類: ★1種（歩くだけ、踏むと倒せる） / 2種（甲羅など） / 3種以上
11. ブロック: ★?ブロックでコイン / レンガ破壊 / なし
12. コイン・スコア: ★コイン数と100点/枚 / スコアなし
13. パワーアップ: ★なし / キノコ（大きくなる）
14. 穴・落下死: ★あり

## D. 勝敗とフロー
15. ゴール: ★旗に触れるとクリア / 右端到達
16. 制限時間: ★なし / 300秒
17. 画面: ★タイトル→プレイ→クリア/ゲームオーバー / プレイ画面のみ

## E. 非機能
18. FPS: ★60固定 / 30
19. 画面サイズ: ★内部解像度 256x240 を整数倍拡大 / 任意
20. 対応OS: ★macOS（開発機）のみ / Win・Linuxも

## マリオ風ゲームの最小構成チェックリスト（要件の抜け確認用）
- [ ] 左右移動（加速・減速・最大速度） [ ] ジャンプ（高さ・可変・重力・落下上限）
- [ ] 床・壁・天井との衝突 [ ] 足場の端での挙動（落下開始）
- [ ] 敵の移動と壁・崖での反転 [ ] 踏みつけ撃破（上から）と被ダメージ（横・下から）
- [ ] 穴への落下死 [ ] ゴール到達 [ ] ゲームオーバー条件とリスタート
- [ ] カメラ追従（左へ戻らない・ステージ端でクランプ） [ ] ステージデータの形式と読み込み
