# テストケース導出の技法

## 1. 同値分割 + 境界値（閾値がある振る舞いは必ず）
閾値 T に対し「T の直前 / T ちょうど / T の直後」の3点。
例: 最大水平速度 90 px/s → 89.9 / 90 / 加速を続けても 90 のまま。
例: コヨーテタイム 0.08 s → 離地後 0.07 s でジャンプ可 / 0.08 s で可 / 0.09 s で不可。

## 2. 状態遷移
状態と遷移を表にし、**全遷移を1TC**、**禁止遷移も1TC** にする。
例: Player 状態 {地上, 上昇, 下降, 死亡}。死亡中はジャンプ入力を無視する（禁止遷移）。

## 3. 衝突・位置関係（AABB）
同じ衝突でも「接触方向」ごとに別 TC: 上から / 下から / 左から / 右から / 角（どちらの軸が先に解決されるか）。
隙間ちょうど（ぴったり通れる / 1px 足りない）を境界として含める。

## 4. 時間
- `dt` を 1/60 で 60 回回した結果と、`dt` = 1 で 1 回回した結果が許容誤差内で一致するか（フレームレート独立性）。
- `dt = 0` では何も動かない。巨大な `dt`（例: 1.0）で壁をすり抜けない。

## 5. 異常系・入力
- 同時入力（左+右）、入力なし、ジャンプ連打、押しっぱなし（ジャンプは1回だけ）。
- 範囲外ステージデータ（不正文字・行の長さ不一致）→ 具体的な例外型とメッセージ。

## 6. 回帰
バグ修正時は、まず再現する TC を追加（Red にして原因を固定）してから直す。

## 良い TC / 悪い TC
| 悪い | 良い |
|---|---|
| 右に動く | 静止中のプレイヤーに右入力を dt=1/60 で 1 回与えると vel.x == 12.0（ACCEL=720 px/s^2） |
| ジャンプできる | 地上（on_ground=True）でジャンプ押下すると vel.y == -JUMP_SPEED、on_ground == False |
| 敵を倒せる | 下降中(vel.y=200)のプレイヤー底面が敵の上面から 4px 以内で重なると敵は defeated、プレイヤー vel.y == -BOUNCE_SPEED |
