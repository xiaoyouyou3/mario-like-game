# KN-001 APK が 29.5MB に肥大し、Web 版の読み込みが遅い

| 項目 | 内容 |
|---|---|
| 分類 | ビルド |
| 確度 | 確認済み |
| 関連 | REQ-102 / DES-018 |
| 記録日 | 2026-11-13 |

## 症状
APK が 29.5MB に肥大し、Web 版の読み込みが遅い

## 原因
pygbag はビルド対象フォルダの中身を丸ごと APK にする。プロジェクト直下でビルドしたため、`.venv`（約 1550 ファイル）・`docs/`・`.claude/`・`tests/`・各種キャッシュが入った。ゲーム本体（`main.py`・`src`・`assets`）は 36KB 程度。

## 対処
必要なファイルだけを一時フォルダにコピーしてビルドする。`scripts/build_web.sh` にまとめた。結果: APK が 19.8KB になった。

## 再発防止
ビルドは必ず `scripts/build_web.sh` を使う。ビルド後に `unzip -l build/web/*.apk` で中身を確認する（macOS では `LC_ALL=C` を付ける）。

## 根拠
`unzip -l` で `assets/.venv/...` が 1550 ファイルあることを確認。ビルド後は 31 ファイル・38,719 バイト。
