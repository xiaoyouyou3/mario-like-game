# KN-003 ページが「Loading, please wait ...」のまま止まる

| 項目 | 内容 |
|---|---|
| 分類 | ローカル配信 |
| 確度 | 原因は推測・対処は確認済み |
| 関連 | REQ-103, REQ-105 |
| 記録日 | 2026-11-13 |

## 症状
ページが「Loading, please wait ...」のまま止まる

## 原因
新規プロファイルのヘッドレス Chrome では、同じビルドで「Ready to start ! Please click/touch page」まで進んだ。サーバーとビルドは正常。ブラウザ側に古い状態が残っていたことが原因と推測している（テストサーバーは初回に CDN から同期取得するため、その間ほかのリクエストが待たされることも影響した可能性がある）。

## 対処
シークレットウィンドウで開くと動いた。動いたら画面をクリックする（ブラウザの音声の制限により、クリックするまで始まらない）。強制再読み込み（Cmd+Shift+R）では直らなかった。

## 再発防止
止まったら、まずシークレットウィンドウで試す。`main.wasm`（約 13MB）と `main.data`（約 6.7MB）が CDN と同じサイズでキャッシュされているかも確認する。

## 根拠
ヘッドレス Chrome の CDP で `infobox` が「Ready to start」になることを確認。キャッシュのサイズは CDN の content-length と一致。ユーザーのブラウザで動いたことも確認された。
