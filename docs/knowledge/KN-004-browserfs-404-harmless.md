# KN-004 コンソールに `//cdn/0.9.3//browserfs.min.js` の 404 が出続ける

| 項目 | 内容 |
|---|---|
| 分類 | ローカル配信 |
| 確度 | 確認済み |
| 関連 | - |
| 記録日 | 2026-11-13 |

## 症状
コンソールに `//cdn/0.9.3//browserfs.min.js` の 404 が出続ける

## 原因
pygbag 0.9.3 のテンプレートが、CDN に存在しないファイルを読みに行っている（本物の CDN でも 404）。ゲームの動作には影響しない。

## 対処
対処は不要。止まる原因はほかにあるので、最初の 404 以外のエラーを探す。

## 再発防止
このエラーを調査の起点にしない。

## 根拠
`https://pygame-web.github.io/cdn/0.9.3/browserfs.min.js` が 404 であることを curl で確認。このエラーがある状態でもゲームは動いた。
