# KN-007 スマホ実機で初めて 3 つの問題が見つかった

| 項目 | 内容 |
|---|---|
| 分類 | 要件・設計の見落とし |
| 確度 | 確認済み |
| 関連 | REQ-044, REQ-052〜058, REQ-102 |
| 記録日 | 2026-11-13 |

## 症状
スマホ実機で初めて 3 つの問題が見つかった

## 原因
(1) 整数倍の拡大だけでは、iPhone の横向き（高さ約 375px）で倍率が 1 に固定され、画面が小さい正方形のままになった。(2) 仮想ボタンの位置を要件が決めておらず、ゲーム画面に半透明で重ねたため、マリオや敵と重なった。(3) 操作パネルを一様な地面で塗ったため、穴が 32px の凹みに見えた。どれも自動テストと PC での確認では出なかった。

## 対処
変更要求として、要件（REQ-102・052〜058）→ 基本設計 → テスト仕様 → TDD の順に直した。画面を 592x304 の横長にし、小数倍の拡大、操作パネル、列ごとの地面と穴の描画にした。

## 再発防止
画面の見た目に関わる要件は、受入条件に「重ならない」「何 px 以上」など観測できる条件を入れる。拡大方法・端末の解像度・向きを要件の段階で確認する。見た目を変える修正のあとは、画面外描画の PNG で確認してから公開する。

## 根拠
公開サイトをスマホで見たユーザーの指摘。修正後に画面外描画の PNG で、ボタンが操作パネル内でマリオ・敵と重ならないこと、穴が下端まで黒く続くことを確認。
