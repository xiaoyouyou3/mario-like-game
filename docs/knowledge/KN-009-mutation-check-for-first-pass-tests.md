| 確度 | 確認済み |
| 関連 | - |
| 記録日 | 2026-11-13 |

## 症状
Red にしたとき、最初から通ってしまうテストがある

## 原因
既存の実装が条件を満たしているテスト（TC-106、TC-124）は、実装前でも通る。通ったテストが有効かどうか、そのままでは分からない。

## 対処
実装をわざと壊して、そのテストが失敗することを確認する（変異テスト）。例: ボタンを画面の外へ置く → TC-106 が失敗、ボタンを重ねる → TC-124 が失敗。確認後は `git diff` で元に戻っていることを確認する。結果を tdd-log に残す。

## 再発防止
最初から通る TC は、必ず変異テストで有効性を確認して記録する。スタブは、全ケースが `AssertionError` で落ちる値（反転した値など）にする。

## 根拠
`tdd-log.md` に TC-106[right] と TC-124[left-right] の失敗を記録。TC-129〜131 では反転スタブで 7 件すべて AssertionError。
