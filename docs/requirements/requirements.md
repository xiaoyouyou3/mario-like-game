# 要件定義書

最終更新: 2026-11-03 / 状態: 承認済（REQ-051 追加済み）

## 1. 目的・ゴール
スーパーマリオブラザーズ風の横スクロールアクション（1面）を作る。作者本人が TDD とコンテキストエンジニアリングを学ぶために作り、macOS と iPhone のブラウザで遊べる。

## 2. スコープ
- 含む: 1面のプレイ、歩行敵と甲羅敵、?ブロックのコイン、コイン数とスコア、残機3、旗でクリア、タイトル/クリア/ゲームオーバー画面、キーボード操作、iPhone 用の画面上の仮想ボタン、CC0 のドット絵素材
- 含まない（明示）: 音（効果音・BGM）、可変ジャンプ、パワーアップ、制限時間、複数ステージ、ゲームパッド、Windows・Linux 対応、iPhone ネイティブアプリ、縦画面表示、セーブ機能

## 3. 機能要件
数値は提案値。タイルの1辺は 16 px。

### 3.1 プレイヤーの移動
| ID | 要件（1文） | 優先度 | 受入条件（観測可能な値・状態） |
|---|---|---|---|
| REQ-001 | プレイヤーは←→入力で水平移動できる | Must | 地上で右入力を 0.5 秒継続すると x 速度が 0 より大きく 90 px/s 以下である。左入力では x 速度の符号が逆になる |
| REQ-002 | プレイヤーはXを押している間、ダッシュで加速できる | Must | 地上でXと右入力を 1.0 秒継続すると x 速度が 150 px/s に達し、150 px/s を超えない |
| REQ-003 | プレイヤーは水平入力を離すと減速して止まる | Must | 地上で右入力を 0.5 秒継続した後に入力を離し 0.5 秒経過すると x 速度が 0 である |
| REQ-004 | プレイヤーは地上でZを押すとジャンプできる | Must | 地上でZを押した直後に y 速度が上向き（負）になる |
| REQ-005 | プレイヤーは空中でZを押してもジャンプできない | Must | 空中でZを押しても y 速度が上向きに変化しない |
| REQ-006 | ジャンプの高さはZを押している時間に依存しない | Must | Zを 1 フレームだけ押した場合も押し続けた場合も、最高到達点は開始位置から 62 px 以上 66 px 以下の上方である |
| REQ-007 | プレイヤーの落下速度は上限を超えない | Must | 落下中の y 速度（下向き）が 240 px/s を超えない |

### 3.2 地形との衝突
| ID | 要件（1文） | 優先度 | 受入条件（観測可能な値・状態） |
|---|---|---|---|
| REQ-008 | プレイヤーは床タイルの上に立てる | Must | 落下中に床タイルへ達すると、プレイヤーの下端が床の上面に一致し y 速度が 0 になる |
| REQ-009 | プレイヤーは壁タイルを通り抜けられない | Must | 壁に向かって移動し続けてもプレイヤーの矩形が壁の矩形と重ならず、x 速度が 0 になる |
| REQ-010 | プレイヤーは天井タイルに頭が当たると上昇が止まる | Must | 上昇中に天井へ当たると y 速度が 0 以上（下向きまたは静止）になる |
| REQ-011 | プレイヤーは足場の端を越えると落下を始める | Must | 足元の床がなくなった次のフレームから y 速度が下向きに増加する |

### 3.3 敵
| ID | 要件（1文） | 優先度 | 受入条件（観測可能な値・状態） |
|---|---|---|---|
| REQ-012 | 歩行敵は一定速度で水平に歩く | Must | 地上の歩行敵の x 速度の大きさが 30 px/s である |
| REQ-013 | 歩行敵は壁に当たると進行方向を反転する | Must | 壁に接触した次のフレームで x 速度の符号が逆になる |
| REQ-014 | 歩行敵は足場の端に達すると進行方向を反転する | Should | 次の一歩の足元に床がないとき、x 速度の符号が逆になり落下しない |
| REQ-015 | プレイヤーが落下中に歩行敵を上から踏むと、歩行敵が消える | Must | プレイヤーが下向きの y 速度で、下端が敵の上半分に重なると、その敵がステージから取り除かれる |
| REQ-016 | プレイヤーは敵を踏むと上へ跳ね返る | Must | 敵を踏んだ次のフレームで y 速度が上向きになる |

| REQ-018 | 甲羅敵は歩行敵と同じ速度で歩く | Must | 地上の甲羅敵の x 速度の大きさが 30 px/s である |
| REQ-019 | プレイヤーが甲羅敵を上から踏むと、甲羅敵は静止した甲羅になる | Must | 踏んだ次のフレームで甲羅敵の状態が「静止甲羅」になり、x 速度が 0 である |
| REQ-020 | プレイヤーが静止甲羅に触れると、甲羅がプレイヤーと反対の向きに滑走を始める | Must | 触れた次のフレームで甲羅の状態が「滑走」になり、x 速度の大きさが 200 px/s で、向きがプレイヤーから甲羅へ向かう向きである。プレイヤーは死亡しない |
| REQ-021 | 滑走する甲羅は壁に当たると進行方向を反転する | Should | 壁に接触した次のフレームで x 速度の符号が逆になり、大きさは 200 px/s のままである |
| REQ-022 | 滑走する甲羅は歩行敵に触れるとその歩行敵を消す | Should | 触れた次のフレームで歩行敵がステージから取り除かれる |
| REQ-023 | プレイヤーが滑走する甲羅を上から踏むと、甲羅は静止する | Should | 踏んだ次のフレームで甲羅の状態が「静止甲羅」になり、x 速度が 0 である |
| REQ-024 | プレイヤーは滑走する甲羅に、滑走開始から 0.2 秒経過した後に踏みつけ条件を満たさずに触れると死亡する | Must | 滑走開始から 12 フレーム経過後の接触が起きた次のフレームで、プレイヤーが死亡状態になる |
| REQ-049 | 滑走を始めた甲羅は、開始から 0.2 秒間はプレイヤーを死亡させない | Must | 滑走開始から 12 フレーム以内の接触では、プレイヤーが死亡状態にならない |

## 5. 用語
- タイル: ステージを構成する 16x16 px の正方形
- 踏みつけ条件: プレイヤーが下向きの y 速度で、下端が敵の上半分に重なっていること
- 静止甲羅: 踏まれた甲羅敵の状態。x 速度が 0
- 滑走: 甲羅が 200 px/s で水平に動く状態
